# مأوى — تطبيق إسلامي شامل

وقفٌ لله تعالى، صدقة جارية عن صاحبه وعن والده.

## ما في التطبيق

- **القرآن الكريم** كاملاً بالرسم العثماني، مع ترجمة المعاني بالإنجليزية والفرنسية والأردية والإندونيسية والتركية، وخطة لختم المصحف.
- **مواقيت الصلاة** بتحديد الموقع تلقائياً أو باختيار مدينة من مدن العالم، بتسع طرق حساب، مع تنبيه عند دخول كل صلاة.
- **الأذكار:** الصباح، المساء، بعد الصلاة، النوم، الاستيقاظ، المسجد، أدعية مأثورة، أدعية للوالدين، وأذكارك الخاصة.
- **المسبحة الإلكترونية** وإحصائيات يومية للتسبيح والاستغفار.
- **أسماء الله الحسنى** بمعانيها، و**الأربعون النووية** بالعربية مع الترجمة الإنجليزية.
- **بوصلة القبلة**، و**متابعة الصلوات**، و**التقويم الهجري** بالمناسبات، و**حاسبة الزكاة**.
- ست لغات للواجهة: العربية، English، Français، اردو، Bahasa Indonesia، Türkçe.

## بناء ملف التطبيق (APK) دون تثبيت أي شيء

المشروع فيه بناء آلي على GitHub:

1. أنشئ مستودعاً جديداً على github.com (مثلاً باسم `maawa`).
2. ارفع كل ملفات هذا المجلد إليه، ومنها المجلد المخفي `.github`.
3. افتح تبويب **Actions** في المستودع. سيبدأ البناء وحده، ويستغرق نحو 10 دقائق.
4. عند انتهائه، افتح عملية البناء ونزّل الملف **maawa-apk** من أسفل الصفحة، ثم ثبّته على هاتفك.

## البناء على حاسوبك (اختياري)

بعد تثبيت Flutter:

```bash
flutter create --platforms=android --org com.maawa --project-name maawa .
python3 tool/patch_android.py
flutter pub get
dart run flutter_launcher_icons
flutter build apk --release
```

## النشر على Google Play

يحتاج النشر إلى حساب مطوّر في Google Play (رسوم لمرة واحدة) وتوقيع التطبيق بمفتاح خاص بك، ثم بناء ملف `appbundle` بدل `apk`.
